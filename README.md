# Boîte à Outils Superviseur

Application locale de suivi pour superviseur : Update_perf, Config FDR, base Équipe, tableau de bord des 4 activités (Bouygues, Driiveme, LegalPlace, Stych), **Alimentation DATA** — tous les imports, commune aux 4 activités — et Scorecard par projet.

## Logo et icône de l'application

Le logo suit l'identité visuelle : tuile arrondie couleur **midnight** (#002032) avec un filet **seafoam**, une **boîte à outils** seafoam d'où s'élancent **trois barres ascendantes** (progression seafoam puis **jaune** objectif atteint). Il est intégré partout : favicon de l'onglet (embarqué dans index.html, l'application reste un fichier unique), logo de la barre supérieure, écran d'accueil. Les fichiers sources sont livrés à côté du README : `logo.svg` (vectoriel), `logo-512.png`, `logo-192.png` et `logo-180.png` (icône raccourci / écran d'accueil mobile).

## Ouvrir l'application (2 étapes)

1. Dézippez le fichier `boite-outils-superviseur.zip`.
2. Double-cliquez sur `index.html` : l'application s'ouvre dans votre navigateur (Chrome, Edge ou Firefox). C'est tout : aucune installation, aucun internet requis.

## Ce que contient cette version (étape 1)

- **Accueil** : à l'ouverture de l'outil, un écran de bienvenue vous demande de choisir le projet de destination (Bouygues, Driiveme, LegalPlace ou Stych). Après le choix, vous arrivez sur le tableau de bord ; vous changez de projet à tout moment via le menu ACTIVITÉ en haut à droite. Pour revenir à l'accueil : entrée **Accueil** en haut du menu latéral, ou clic sur le titre de l'application en haut à gauche.
- **En-tête fixe** : menu hamburger en haut à gauche (navigation), menu déroulant en haut à droite pour basculer entre les 4 activités.
- **Tableau de bord** : tableau de bord interactif inspiré de votre tableau « Delivery Prod » — 6 jauges % ADV (KPI 1, KPI 2, KPI 1&2, targets CNX, production -3 mois et +3 mois), atteinte KPI 1&2 par mois (CLT vs CNX), effectif par séniorité et Delivery KPI 1 et 2. Trois menus déroulants à choix multiple : **Activités**, **Période** (les 12 mois de l'année, avec le nombre de lignes Update_perf de chaque mois) et **Semaines**, plus un bouton Réinitialiser. Les graphiques sont synchronisés avec vos données Update_perf : seuls les mois sélectionnés contenant des lignes affichent des barres. Après toute modification dans Update_perf (ajout, modification, suppression ou restauration), les filtres se resynchronisent automatiquement au retour sur le tableau de bord.
- **Update_perf** (menu Performance) : outil de renseignement des performances.
  - Formulaire de saisie par flux, mois et semaine ; KPI 1 et KPI 2 pré-remplis selon votre référentiel (targets et type ASCENDANT/DESCENDANT).
  - Calculs automatiques identiques à votre fichier Excel : R/O (réalisé/objectif, ou 2 - réalisé/objectif si DESCENDANT), R/O 1&2 (moyenne), quadrant Q1 à Q4, ADV LIFTED total et pourcentages de conseillers sur target. Les ratios R/O sont affichés en pourcentage, base 100 % = target atteinte.
  - Bloc optionnel "Conseillers (ADV)" : blocs "Client target - 3 mois", "Client target + 3 mois" et "CNX target - 3 mois". Les colonnes WH et PROJECTION ne se saisissent plus : elles sont calculées automatiquement depuis la Config FDR du flux, en référence au mois de la ligne — PROJECTION NB ADV CLT TARGET 1&2 et NB ADV ON WH TARGET = OT Kpi1&2 du mois ; PROJECTION % = OT Kpi1&2 ÷ effectif cartographié ; ECART A LA PROJECTION = NB réel sur target client − projection. Toute modification de la Config FDR recalcule ces valeurs sur toutes les lignes du mois concerné.
  - Historique : reprise intégrale des 126 lignes de votre fichier `update perf.xlsx` (JUILLET S32 à OCTOBRE S47), filtres par mois, semaine et recherche, modification et suppression ligne par ligne.
  - Export CSV avec exactement les 54 colonnes de votre fichier.
- **Config FDR** (menu « CONFIG ») : feuille de route annuelle reprise de vos données (120 lignes = 10 flux x 12 mois).
  - Colonnes identiques à votre format : Projets, Mois, eff carto, OT Kpi1, OT Kpi2, OT Kpi1&2, eff carto CNX, OT Kpi1 CNX, OT Kpi2 CNX, OT Kpi1&2 CNX. Dans la colonne Projets, le nom du projet (ex : STYCH-TMM-AS) s'affiche en gras, avec le code flux (ex : W0ZVYG) en dessous en police normale.
  - Tableau directement modifiable : chaque case modifiée est enregistrée automatiquement.
  - Filtre par mois, vue filtrée par activité (menu déroulant en haut à droite), export CSV au format d'origine.
- **Menu « CONFIG »** : regroupe **Alimentation DATA** (tous les imports de l'outil, disponible pour les 4 activités) et la **Config FDR** ; les outils propres à un projet s'y ajoutent le cas échéant. La **Scorecard**, commune aux 4 projets, a sa propre entrée dans le menu principal, juste sous « Tableau de bord ». Le groupe déroulant **« Performance »** contient Update_perf, Perf. projet, Perf. CC et **Prime**. Le groupe déroulant **« Mes heures »** du menu latéral contient les entrées « Mes heures », « Planning » et « Congés » (chaque groupe se replie et se déplie au clic, et se déplie tout seul quand une de ses pages est active). Règle générale : **tous les menus déroulants sont à sélection multiple** (plusieurs valeurs cochables ; rien de coché = tout voir).
  - **Alimentation DATA (menu CONFIG, toutes activités)** — **l'unique porte d'entrée des imports** de l'outil, adaptée au projet sélectionné : le fichier **« Validation Planning »** pour les 4 activités (il alimente la page Planning du menu « Mes heures ») ; pour le projet Stych, en plus : import DMT + remplissage SATCLI + import Taux de joignabilité. La liste des semaines planning chargées (avec suppression ✕) est gérée ici.
    - **Import du fichier d'appels Ringover** (CSV, séparateur point-virgule) avec les colonnes UserName, StartTime et InCallDuration. L'import reconnaît les 8 agents de l'équipe par leur nom dans le fichier (Fanyah Rato, Marie joseph, Than-jhi Braster, Levy Michou RAVALITERA, Marie Anna RAHAJA, Tojo Andrianaly, Josie Francia Razafimaharitra, Tahina Arinoro Rakotomanana) et ignore les utilisateurs hors équipe.

Les valeurs de référence (« Maj Satcli » : août, septembre et octobre 2026) sont intégrées à l'outil et préremplies ; enregistrer sur un mois déjà rempli remplace les anciennes valeurs. Le bouton « Rétablir les valeurs de référence » annule vos saisies.

## Où sont enregistrées vos données

Dans votre navigateur, sur votre ordinateur (technologie localStorage). Elles restent après fermeture du navigateur, mais sont propres à cet ordinateur et à ce navigateur. Pensez à faire régulièrement une sauvegarde via le menu "Données & sauvegarde". Si vous ouvrez l'application depuis un autre ordinateur, importez votre fichier de sauvegarde JSON pour retrouver vos données. Les **plannings importés** (une fiche par semaine) sont conservés à part, en IndexedDB (base « bo-sup », magasin « planning »), sur le même ordinateur et le même navigateur.

## Confidentialité

La page Équipe contient des données personnelles (noms, e-mails, identifiants). Tant que l'application reste en local sur votre ordinateur, rien n'est partagé. Si plus tard vous la publiez sur une adresse internet publique (Cloudflare), toute personne ayant le lien pourra voir ces données : nous prévoirons alors une protection (accès par mot de passe) ou une version sans données personnelles.

## Prochaines étapes prévues (dans l'ordre)

1. Vous validez le squelette et l'outil Update_perf (et me dites les ajustements voulus).
2. On construit les modules suivants un par un (par exemple Congés ou Prime).
3. Vous créez votre compte GitHub ; je vous guide pas à pas pour déposer le code.
4. Vous créez votre compte Cloudflare (Pages) ; on connecte le dépôt GitHub : le site est en ligne avec une adresse internet.
5. Ensuite, chaque amélioration déposée sur GitHub met à jour le site automatiquement.
